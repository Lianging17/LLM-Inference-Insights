
| 东西               | 它负责什么                   |
| ---------------- | ----------------------- |
| `instruction.md` | 告诉 Agent **做什么**        |
| `environment/`   | 保证 Agent **在哪里做、有什么可用** |
| Agent            | **怎么做**                 |
| `solution`       | Agent **最终做出来的东西**      |
| `tests/`         | 判断 **做得对不对**            |
| `grader`         | 把测试结果变成 **0/1 分**       |
| **solution**     | Agent **交上来的答案**        |
| **test**         | 老师拿来**检查答案的题/程序**       |
| **grader**       | 根据检查结果**算最终分数的程序**      |
